Grain — film stock picker

Proposed change to the Develop panel's existing Grain section (RFC-0022 / M5.8). It reuses the panel's own pattern — a labelled dropdown row above the sliders, like Profile under White Balance — and adds two sliders (Colour, Tone). Every stock only loads slider values; nothing is hidden behind the picker. The right-hand panel is live: pick a stock, drag a slider, press Reset.

Live (interactive)

  • Film row — dropdown, grouped Colour negative / Black & white, then None. A native <select> with <optgroup>s (same control as WB Profile), so keyboard, screen-reader and OS menu behaviour come for free.
  • Custom — derived, never stored: shown whenever the five slider values differ from the selected stock's preset. The stock's numbers are stored in the edit, so retuning a preset later never changes a saved edit.
  • Reset to <stock> — appears only while Custom and a stock was last chosen; restores that stock's five values. The panel's global Reset still clears the whole edit.
  • Caption — one line of character plus the provenance tag from RFC-0022 §2.4 (D data-derived, R reasoned, A aesthetic) so the "approximation, not a reproduction" statement is visible in the product, not only in the RFC.
  • Colour slider is dimmed (not disabled) for black & white stocks, per the panel's existing "dimmed controls stay interactive" rule (.panel-hidden, RFC-0013).
  • Stock values shown are the RFC §2.4 proposal and will be tuned by eye in slice 4.
